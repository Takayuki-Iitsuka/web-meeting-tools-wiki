# アクセシビリティ（字幕・操作性）

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 1. 字幕・文字起こし
| ツール | 内容 | 信頼度 |
|---|---|---|
| Microsoft Teams | ライブキャプション、CART 文字起こしに対応 | ✅（AVD 資料）|
| Slack ハドル | キャプションは**英語のみ**で、ハドル終了後は保存されない | ✅ |
| Webex | 字幕・ハイライトは英・仏・独・西語のみ、会議後の文字起こしは英語のみ（プラン表の注記）| ✅ |
| Google Meet | キャプション機能の言語対応 | ⚠️ 未確認 |
| その他 | ⚠️ 未確認 | |

> 日本語字幕が必要な場合は、**日本語対応が公式に明記されているか**を事前に確認すること。

## 2. 運用のコツ ⚪
- 発言者は名乗ってから話し、同時発話を避ける。
- 資料は事前配布し、画面共有では読み上げる。
- 字幕の誤りを前提に、重要事項はチャットにも記載。
- 聴覚障害のある参加者には、手話通訳者のピン留めや文字起こしの併用を検討。

## 3. 操作性 ⚪
- キーボードショートカットでミュート／カメラ切替ができるツールが多い（一覧は各社ヘルプ）。
- スクリーンリーダー対応は機能差が大きい ⚠️ 要確認。
- 色覚・コントラスト・文字サイズの設定を事前に。
