# 画面共有の OS 別差異

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

| 項目 | Windows | macOS | Android | iPadOS |
|---|---|---|---|---|
| 仕組み | アプリ内蔵の画面／ウィンドウ取得 ⚪ | 同左＋**画面収録権限が必要** ⚪ | OS の画面キャプチャ（MediaProjection）⚪ | OS のブロードキャスト機能 🔶 |
| 共有単位 | 画面／ウィンドウ／アプリ ⚪ | 同左 ⚪ | 画面全体が中心 🔶 | 画面全体 🔶 |
| 端末内音声 | ツールのオプションで可 ⚪ | 制限あり、ツール依存 ⚪ | 端末・OS・ツール依存 ⚠️ | 共有されない／不安定の報告 🔶 |
| 通知の映り込み | あり | あり | あり | あり（全画面のため特に注意）|

## 確認できたツール別の事実
- Slack ハドル: 同時共有は最大2人、PC はアプリ／ウィンドウ／画面を選択、スマホは「…」→画面を共有 ✅。描画は Mac／Windows のデスクトップアプリのみ ✅。
- FaceTime: Android／Windows のゲストは画面共有と SharePlay が使えない ✅。
- Teams（AVD 環境）: アプリ単位の共有は iOS/iPadOS・Android で非対応、システム音声共有は iOS/iPadOS・macOS で非対応 ✅（VDI の場合に限る）。
- Jitsi: 共有が白っぽい時は OS の HDR をオフ ✅。

詳しいコツは [画面共有のテクニック](screen-sharing-tips.md)。
