# セキュリティ・プライバシー チェックリスト

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 1. 開催前 ⚪
- [ ] 会議リンクを公開SNSに載せない。推測されにくいルーム名／会議IDを使う（Jitsi 公式FAQの推奨 ✅）。
- [ ] パスコードを設定（Jitsi は会議終了でパスワードが外れ、毎回再設定が必要 ✅）。
- [ ] 待機室（ロビー）を有効にし、参加者を承認する。
- [ ] 共同ホスト／モデレーターを最小限にする。
- [ ] E2EE（End-to-End Encryption／端末間暗号化）が必要か判断。有効にすると一部機能が制限される場合がある ⚪。
- [ ] 録画・文字起こし・AI要約の可否と保管先を決める。

## 2. 開催中 ⚪
- [ ] 参加者名簿を確認し、未知の参加者は退室させる。
- [ ] 録画・文字起こし・AI機能を開始する前に**参加者へ告知し同意を取る**。Meet のメモ機能は開始時に全員へ通知される（青い鉛筆アイコン）🔶。
- [ ] 画面共有は必要なウィンドウのみ。通知をオフ。
- [ ] 機密情報はチャットではなく別経路で。

## 3. 開催後 ⚪
- [ ] 録画データの保存先・閲覧権限・保存期間を確認（Teams の録画は未アップロード分が20日で期限切れ ✅）。
- [ ] AI要約の内容を人が確認してから共有。
- [ ] 不要な録画・文字起こしを削除。
- [ ] 共有リンクの有効期限（Teams は会議リンクに有効期限あり ✅）。

## 4. 組織向け ⚪
- SSO（Single Sign-On／シングルサインオン）、ゲスト参加ポリシー、外部組織との共有範囲、ログ保存を整備。
- 個人情報保護法（日本）・GDPR（EU）等の取扱いは法務に確認。**法的助言ではない**。
