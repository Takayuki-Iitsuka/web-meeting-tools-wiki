# スマホ⇄PC の移動方法

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 1. ツール別（確認できた範囲）
| ツール | 方法 | 信頼度 |
|---|---|---|
| Slack ハドル | モバイルの青いアンテナアイコン→「Join Here」で PC から移動。PC から再参加するとモバイルは外れる | ✅ |
| Microsoft Teams | デスクトップ⇄モバイルの会議移動機能あり。方向性は資料で不一致。同時参加で30秒ほどで切断された報告あり | 🔶 |
| Webex | 「別端末へ会議を移動」の公式記事あり（手順本文は未取得）| ✅存在のみ |
| FaceTime | Apple 端末間は Handoff（⚪）。Windows/Android はブラウザ参加のみ | ✅/⚪ |
| その他 | ⚠️ 未確認 | ⚠️ |

## 2. 共通の手順 ⚪
1. 新端末で同じアカウントにログインし、会議リンク・会議ID・パスコードを用意。
2. 新端末ではマイク・スピーカーをオフにして会議に参加。
3. 接続を確認してから旧端末を退出。
4. 新端末の音声をオンにする。
**同時に2端末で音声を出さない**（ハウリング防止）。

## 3. 失敗しやすい点 ⚪
- 切替中は数十秒の欠落があり得る。重要な発表の直前は避ける。
- アカウントが違うと待機室に入り直しになる。
- 録画・AI機能は旧端末側の状態を引き継がないことがある ⚠️。
