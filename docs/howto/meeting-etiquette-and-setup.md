# 機材・環境・マナー

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 1. 機材 ⚪
- **音声が最優先**: ヘッドセットまたは会議用スピーカーフォン。内蔵マイクは反響しやすい。
- カメラは目線の高さ。窓を背にせず、顔の正面に光源を置く。
- 背景は整理、または仮想背景（端末負荷に注意）。

## 2. 事前準備 ⚪
- 開始5分前に入室し、音声・映像・共有をテスト。
- バッテリーと充電、通知オフ、不要アプリ終了。
- 資料を事前に開く。
- 会議の目的・議題・時間・決定事項を共有。

## 3. 進行マナー ⚪
- 発言しない時はミュート。名乗ってから話す。
- 手を挙げる機能やチャットで質問。
- 録画・AI機能は開始前に告知。
- 終了時に決定事項と担当・期限を復唱。

## 4. 遠隔と対面が混在する場合 ⚪
- 会議室にはエコーキャンセル対応のスピーカーフォンを使用。
- 参加者全員が個別にログインすると会議室でハウリングするため、会議室のマイクを1台に集約。
