# 画面共有のテクニック集

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 1. 共有前 ⚪
- 通知オフ（集中モード）。デスクトップのファイル名・メール・チャットを整理。
- ブックマークバー・タブを非表示、拡大率を125〜150%にして文字を読みやすく。
- 資料は事前に開く。機密資料は別ウィンドウに分け、**ウィンドウ単位で共有**。
- 2画面なら、共有用と発表者ノート用に分ける。

## 2. 共有中 ⚪
- 開始直後に「画面が見えますか」「音が聞こえますか」と確認。
- ポインタをゆっくり動かし、強調には注釈機能を使う（Slack ハドルは描画に対応 ✅）。
- 共有を一時停止できるツールでは、別資料に切り替える間は停止。
- 画面共有と自分の映像を同時に出せるツールでは小窓を残す（Teams は対応 ✅）。

## 3. 動画・音声を共有する ⚪
- 「コンピューター音声／デバイス音声を共有」のチェックを入れる。
- ハウリング防止にヘッドセットを使用。iPadOS は端末内音声が乗らない報告があるため PC を推奨 🔶。
- 動画再生が滑らかでない時は、動画向けの最適化オプション（ある場合）を有効化。

## 4. 共有後 ⚪
共有を停止したか確認。録画を共有する場合は、写り込んだ個人情報がないか確認。

## 5. トラブル ⚪
| 症状 | 対処 |
|---|---|
| 共有画面が黒い | macOS の画面収録権限、保護コンテンツ（DRM）の可能性 |
| 共有画面が白っぽい | OS の HDR をオフ（Windows: Win+Alt+B）✅ |
| 相手の画面が荒い | 共有範囲を狭める、解像度を下げる、アニメーションを減らす |
