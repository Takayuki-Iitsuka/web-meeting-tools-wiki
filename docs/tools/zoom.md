## 1. 概要
Zoom Communications 提供のビデオ会議サービス。会議（Meetings）を中核に、チャット、ウェビナー、電話（Phone）等を束ねた統合製品群が「Zoom Workplace」。⚪

## 2. 特徴
- 専用クライアントによる安定した音声・映像品質と、ネットワーク状況に応じた帯域の自動最適化。🔶
- 参加者はアカウント無しでリンクから参加可能。⚪
- ブレイクアウトルーム（Breakout Room／分科会室）、投票、ホワイトボード、クラウド録画、ウェビナー等の機能が豊富。⚪
- E2EE（End-to-End Encryption／端末間暗号化）は設定で有効化できるが、有効時は一部機能が制限される。⚪ ⚠️詳細未確認

## 4. 無料プランで使える範囲
- 参加者上限 100 人、1 会議 **40 分**まで（3人以上の場合の制限。1対1の扱いは ⚠️ 未確認）。🔶
- 録画・字幕・ブレイクアウト等の無料プラン可否: ⚠️ 未確認。

## 5. PC・端末への負荷
| 項目 | 内容 |
|---|---|
| 最小要件（Zoom Video SDK 文書の記載） | デュアルコア 2GHz 以上・RAM 4GB 🔶 |
| 推奨 | クアッド 2.5GHz 以上・RAM 16GB 🔶 |
| Web 版 | 会議中の使用メモリ約 1〜1.5GB、システム RAM 8GB 推奨（Windows/macOS）🔶 |
| 1080p 帯域 | 受信 1.8〜2.5Mbps、送信 3.0Mbps 前後など資料で不一致（旧資料含む）🔶。Zoom は帯域を自動最適化 |
| 負荷が上がる場面 | 仮想背景・ギャラリー表示の多人数・HD映像・画面共有同時利用 ⚪ |
| 軽減策 | 仮想背景オフ、ギャラリー表示数を下げる、HD映像を切る、不要アプリ終了 ⚪ |
※ Video SDK の要件は Meeting アプリと同一とされるが、直接の確認は未実施。バッテリー消費・発熱の定量値は ⚠️ 未確認。

## 6. OS別対応
Windows / macOS / Android / iPadOS とも専用アプリあり ⚪（最小OSバージョンは ⚠️ 未確認、接続不可のため公式要件ページを取得できず）。

## 7. 長所・短所
- 長所: 機能が豊富、参加が簡単。⚪
- 短所: 無料は 40 分制限。有料でも Pro は 100 人どまり。🔶
