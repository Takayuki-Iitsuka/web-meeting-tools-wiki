## 1. 概要
コミュニティ向けチャット。サーバのボイスチャンネルでビデオ通話・画面共有（Go Live）が可能。⚪

## 2. 特徴
- ビデオ付きボイスチャンネルは **25 人まで**。Nitro でも同じ ✅（Discord 公式表の検索要約）。「Nitro で無制限」とする記事は公式と矛盾 → 採用せず。
- 画面共有は無料で 720p/30fps、Nitro で 1080p/60fps など 🔶（出典が弱い）。

## 3. 料金プラン
Free / Nitro Basic / Nitro の3段階 🔶。価格: ⚠️ 未確認。

## 4. 無料プランで使える範囲
ビデオ通話 25 人まで ✅、画面共有 720p/30fps 🔶。会議の時間制限: ⚠️ 未確認。

## 5. PC・端末への負荷
ゲーム同時利用が前提で、画面共有の高解像度・高fpsは CPU/GPU とアップロード帯域を消費 ⚪（数値は ⚠️ 未確認）。

## 6. OS別対応
Windows / macOS / Android / iPadOS ⚠️ 要確認。

## 7. 長所・短所
- 長所: 常設チャンネルで気軽に集まれる。短所: ビジネス向け管理・会議機能は限定的 ⚪。
