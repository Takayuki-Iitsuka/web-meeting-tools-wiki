# Amazon Chime（終了）

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 概要
AWS のビデオ会議サービス。**2026年2月20日に AWS がサポートを終了** ✅。特別な場合に会議へ参加する用途では引き続き使える旨の記載あり。**Amazon Chime SDK サービスは影響を受けない** ✅。

## 注意
- 新規の会議基盤としては選ばない。開発者向けの SDK は別サービス。
- ブラウザ向けの Chime Web アプリでの参加はアプリ未導入でも可能と案内されている ✅（終了後の運用は⚠️要確認）。
