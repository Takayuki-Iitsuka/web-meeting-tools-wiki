## 1. 概要
Microsoft 365 に統合されたチャット・会議・共同作業基盤。⚪

## 2. 特徴
- Windows / macOS デスクトップアプリ、Web、モバイル。Linux クライアントは終了。✅
- 会議は最長 30 時間、録画は 1 本最大 4 時間または 1.5GB（到達で自動再開）。✅
- 入室不要のゲスト参加、ブレイクアウト、ライブキャプション、CART 文字起こし等。✅（Azure Virtual Desktop 資料での対応確認を含む）
- 大規模: 会議で閲覧専用 10,000 人を追加可（Enterprise のみ）。イベントは Attendee Capacity Pack で最大 100,000 人。✅

## 3. 料金プラン
| プラン | 価格の目安（月額/ユーザー、年払い） | 会議の最大人数 |
|---|---|---|
| Teams（無料） | 0 | 100 人、グループ会議 60 分 🔶 |
| Teams Essentials | 約 $4 🔶（英国ページ £3.10 税別 🔶） | 300 人、最大 30 時間 ✅🔶 |
| Microsoft 365 Business Basic | $6〜7 🔶（Teams 込み/別で差） | 300 人 ✅ |
| Business Standard / Premium | ⚠️ 価格未確認 | 300 人 ✅ |
| Enterprise 系（E3/E5 等） | ⚠️ 価格未確認 | 1,000 人（＋閲覧専用 10,000）✅ |

## 4. 無料プランで使える範囲
- グループ会議は最大 60 分、100 人まで 🔶（コミュニティ回答／比較サイト。公式での再確認が必要）
- 1対1は最大 30 時間とする回答あり 🔶
- ゲストはライセンス不要で会議参加可 🔶

## 5. PC・端末への負荷
| 項目 | 内容 |
|---|---|
| macOS デスクトップ要件 | デュアルコア、RAM 4.0GB、空き 1.5GB、解像度 1200×800 以上、最新3世代の macOS、WebView2 を最新に ✅ |
| Windows 要件 | ⚠️ 未確認（取得した結果に記載なし） |
| Web 版 | モバイルブラウザは非対応、VDI では非推奨 ✅ |
| 傾向 | 常駐アプリで Zoom/Meet より重いとされることが多い ⚪（定量値未確認） |
| 軽減策 | 通知・アニメーションを抑える、カメラ解像度/背景効果を下げる、キャッシュ整理 ⚪ |
| VDI | メディア最適化（WebRTC Redirector）が必要 ✅ |

## 6. OS別対応
Windows / macOS アプリ ✅、Android / iOS・iPadOS アプリ ✅（最小OS値は ⚠️ 未確認）。ブラウザは Edge / Chrome / Firefox（直近3版）、Safari（直近2版、macOS）✅。

## 7. 長所・短所
- 長所: Microsoft 365 との統合、大規模対応。✅
- 短所: 無料は 60 分制限 🔶、PC負荷が比較的高いとされる ⚪。
