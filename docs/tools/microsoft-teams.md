# Microsoft Teams

> 確認日: 2026年11月3日（皇紀2686年・令和8年） ／ ✅ 確認済（出典あり）・⚠️ 未確認

## 概要
Microsoft 365 に統合されたチャット・会議基盤。

## 対応OS
| OS | クライアント | 最小OS要件 | ブラウザ参加 |
|---|---|---|---|
| Windows | ✅ デスクトップアプリ（64/32bit） | ⚠️ 未確認 | ✅ Edge / Chrome / Firefox（直近3版） |
| macOS | ✅ デスクトップアプリ（Intel/Apple silicon 共通） | ✅ 最新3世代の macOS（RAM 4GB・空き1.5GB） | ✅ Safari（直近2版）ほか |
| Android | ✅ アプリ | ⚠️ 未確認 | ✅ 公式は「モバイルブラウザ非対応」 |
| iPadOS | ✅ iOS/iPadOS アプリ | ⚠️ 未確認 | 同上 |

- ✅ Linux 向けクライアントは終了（Web／PWA のみ）。

## 料金・制限
- ✅ Business Basic/Standard/Premium、Teams Essentials: 最大300人。Enterprise 系: 最大1,000人（さらに閲覧専用最大10,000人）。
- ✅ 会議の最大時間は30時間。録画は最大4時間または1.5GBで自動再開。
- ⚠️ 無料版は「グループ会議60分」とする記述を Microsoft Q&A（コミュニティ回答）で確認したのみ。公式ページで要確認。
