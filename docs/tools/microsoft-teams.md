## 1. 概要
Microsoft 365 に統合されたチャット・会議・共同作業基盤。⚪

## 2. 特徴
- Windows / macOS デスクトップアプリ、Web、モバイル。Linux クライアントは終了。✅
- 会議は最長 30 時間、録画は 1 本最大 4 時間または 1.5GB（到達で自動再開）。✅
- 入室不要のゲスト参加、ブレイクアウト、ライブキャプション、CART 文字起こし等。✅（Azure Virtual Desktop 資料での対応確認を含む）
- 大規模: 会議で閲覧専用 10,000 人を追加可（Enterprise のみ）。イベントは Attendee Capacity Pack で最大 100,000 人。✅

## 4. 無料プランで使える範囲
- グループ会議は最大 60 分、100 人まで 🔶（コミュニティ回答／比較サイト。公式での再確認が必要）
- 1対1は最大 30 時間とする回答あり 🔶
- ゲストはライセンス不要で会議参加可 🔶

## 5. PC・端末への負荷
| 項目 | 内容 |

| Windows 要件 | ✅ 1.1GHz・2コア、RAM 4.0GB、空き3.0GB、Windows 10 (10.0.19041)以上（下記追補）|

| VDI | メディア最適化（WebRTC Redirector）が必要 ✅ |

## 6. OS別対応
Windows / macOS アプリ ✅、Android / iOS・iPadOS アプリ ✅（最小OS値は ⚠️ 未確認）。ブラウザは Edge / Chrome / Firefox（直近3版）、Safari（直近2版、macOS）✅。

## 7. 長所・短所
- 長所: Microsoft 365 との統合、大規模対応。✅
- 短所: 無料は 60 分制限 🔶、PC負荷が比較的高いとされる ⚪。

## 8. スマホ⇄PC の移動方法・テクニック
- デスクトップ⇄モバイル間で会議を移す機能がある 🔶（2020年の報道）。基本は、会議に参加したまま別端末で会議に「参加」し、切替を選ぶ流れとされる 🔶。
- 方向性の記述は割れている: 「どちらの方向も可」と「デスクトップ→モバイルのみ」の両説 🔶。最新の公式文書で要確認。
- モバイルとデスクトップへ同時参加すると30秒ほどでデスクトップ側が切断された、というユーザー報告あり 🔶（個別事例）。
- コツ ⚪: 切替の間に会議へ入り直す数十秒の欠落を許容し、重要な場面の直前は避ける。
- 共通のコツ ⚪: 移行中は**音声を出す端末を1台だけ**にする（両方で参加するとハウリング・エコーの原因）。新端末でマイク/スピーカーをオフのまま参加→映像と接続を確認→旧端末を退出→新端末で音声をオン、の順で行う。会議リンク・会議ID・パスコードを事前に控え、新端末で同じアカウントにログインしておく。

## 9. AI連携（議事録・要約）のコツ
- Teams のライブキャプション／CART 文字起こしは対応 ✅（AVD 資料）。
- Copilot・Intelligent Recap（インテリジェントな要約）などの AI 議事録: 提供条件・ライセンス・日本語対応は ⚠️ 未確認（今回の検索で取得できず）。
- コツ ⚪: 文字起こしを会議内で有効にしてから録画を開始する（要約は文字起こしを元にするため）。要確認の前提。
- 共通のコツ ⚪: 開始前に参加者へ録音・文字起こしの同意を取る（社内規程・個人情報の確認）。議題を招待文に書く、発言者は名乗ってから話す、同時発話を避ける、専門用語は事前に共有すると精度が上がる。AIの要約は誤りを含み得るため、決定事項・担当・期限は人が確認してから配布する。日本語の精度・対応は各社で差があり ⚠️ 要確認。

## 10. 画面共有のテクニック
- AVD（仮想デスクトップ）環境では、アプリ単位の共有・システム音声の共有は iOS/iPadOS・Android で非対応、システム音声共有は macOS でも非対応 ✅（VDI 環境に限る）。通常環境の制約は ⚠️ 未確認。
- iPadOS/Android のモバイル共有は全画面共有が中心 🔶。
- コツ ⚪: 画面と映像を同時に出せる（Screen share and video together ✅ 対応と記載）ので、小窓の自分の映像を残して話すと伝わりやすい。
- 共通のコツ ⚪: 画面全体より**ウィンドウ/アプリ単位**で共有する。共有前に通知をオフ（集中モード/おやすみモード）、機密タブ・メール・チャットを閉じる。資料は事前に開き、文字は拡大表示。動画や音を共有する場合は「コンピューター音声/デバイス音声を共有」のオプションを確認し、全員が聞こえるかを最初に確認する。2画面ならプレゼンター用と共有用を分ける。共有を止め忘れない。

## 公式ページによる追補（Microsoft Learn・2026年11月3日取得）
### 動作要件 ✅
| 項目 | Windows デスクトップ | macOS デスクトップ |
|---|---|---|
| CPU | 1.1GHz 以上・2コア（Intel は Turbo Boost 最大周波数で判断）| デュアルコア |
| RAM | 4.0GB | 4.0GB |
| ディスク空き | 3.0GB | 1.5GB |
| 画面 | 1024×768 以上 | 1200×800 以上 |
| OS | Windows 10 バージョン 10.0.19041 以上（**LTSC は非対応**）| 最新3世代の macOS |
| その他 | WebView2 を最新に。DirectX 9 以上＋WDDM 2.0 以上（ハードウェア アクセラレーション）。USB 2.0 カメラ | WebView2 を最新に |
- **大規模会議（10人以上）・Teams Live Events の推奨: 2018年以降の4コア CPU** ✅。アバター／Mesh は RAM 8GB 以上＋4コア ✅。
- Android: 直近4つのメジャーバージョンまで。iOS: 直近2つのメジャーバージョンまで（iPad を含む）✅。**固定の最低バージョン番号は公式に記載なし**（新OSリリースで対象が移動）。
- Web 版: Edge/Chrome/Firefox は直近3版、Safari は直近2版。**モバイルブラウザ非対応**、VDI で非推奨 ✅。
- ブラウザ制約 ✅: ブラウザでは「操作権限の付与/取得」不可（両者がデスクトップアプリである必要）。ブラウザ会議は **受信映像が1ストリーム**（現在の話者または画面共有のどちらか）。Safari は映像が受信のみとされる記述あり（版により異なる ⚠️）。Firefox は OpenH264 プラグインが必要。

### AI（Intelligent recap／要約）✅
- 条件: Microsoft 365 サブスクリプション（Teams 付き）＋ **Teams Premium または Microsoft Copilot ライセンス**。音声の要約（audio recap）は Copilot ライセンスが必要。
- 前提: **文字起こしを有効化**（管理者ポリシー）。録画が許可されていない場合は録画・話者・トピック・チャプターなしの要約になる。
- 「文字起こしを保存しない要約」: Copilot ライセンスが必要。**予定された会議のみ**対象。要約は主催者の OneDrive に読み取り専用の Word 文書として保存。同一組織の Copilot ライセンス保持者のみ閲覧可、**ゲスト・外部参加者は閲覧不可**。主催者が削除可能。
- 録画の保存期間: 録画は最大4時間または1.5GBで自動再開 ✅。
- 日本語対応の可否はこの資料から判別不可 ⚠️。

## 運用ガイド（ホスト／参加者／使い分け）
- **ホスト**: 会議オプションでロビー、発表者、録画・文字起こしの権限を設定 ⚪。AI要約は文字起こしの有効化が前提 ✅。
- **参加者**: 組織外はゲストまたは匿名で参加可 🔶。ブラウザ参加はデスクトップのみ ✅。
- **使い分け**: Microsoft 365 利用組織の定例・大規模会議（最大1,000人、閲覧専用 +10,000）向け ✅。
- **相互運用**: ゲスト参加はライセンス不要 🔶。
