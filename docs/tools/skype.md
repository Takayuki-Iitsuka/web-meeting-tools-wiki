# Skype（終了）

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証）・⚠️未確認

## 概要
Microsoft のビデオ通話サービス。**2025年5月5日（皇紀2685年・令和7年）に終了** ✅（Skype for Business は対象外）。

## 移行 ✅
- Skype の認証情報で Microsoft Teams（無料）にサインインすると、連絡先とチャットが自動で移行される。
- Teams 無料を使わない場合は Skype のデータをエクスポート可能。
- 通話・Skype Number の契約は2025年4月3日まで自動更新。
- 履歴の扱い: 2024年12月〜2025年2月に Skype を利用し、2025年12月1日より前に Teams 無料へ移行した利用者の履歴は Teams 無料で参照可能。それ以外は**2026年4月1日からデータ削除が始まり**、エクスポート申請は2026年6月15日まで可能（完全な履歴とは限らない）。
- 本日（2026年11月3日）時点では、エクスポート申請期限（2026年6月15日）を過ぎている。

## 代替
[Teams](microsoft-teams.md)（無料枠は🔶）、[Google Meet](google-meet.md)、[Zoom](zoom.md) など。
