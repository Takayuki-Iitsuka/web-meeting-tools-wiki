# iPadOS でのビデオ会議

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証、手順名や画面は版により異なる）・⚠️未確認

## 1. 概要
画面が大きく会議端末として使いやすい。一方で画面共有の仕組み（ブロードキャスト）と音声共有に独特の制約がある ⚪🔶。

## 2. ツール別の対応（確認できた範囲）
| ツール | 内容 | 根拠 |
|---|---|---|
| FaceTime | 標準搭載。リンク作成可（iPadOS 15 以降）| ✅ |
| Google Meet | iOS 17 以上（iPadOS の個別記載なし） | ✅ / ⚠️ |
| Microsoft Teams | iOS/iPadOS アプリあり | ✅ |
| Slack ハドル | モバイルアプリ | ✅ |
| その他 | アプリあり ⚪ | ⚠️ 要確認 |

## 3. 画面共有の仕組みと落とし穴
- 多くの会議アプリは iPadOS の画面ブロードキャスト機能で共有する。共有を選ぶとシステムの確認画面が出て、**画面全体**が配信される 🔶。
- そのため通知・他アプリの内容も映る。事前におやすみモード／集中モードを有効にする ⚪。
- **端末内音声（動画・音楽）は共有されない／不安定** との報告あり 🔶。共有に音を乗せたい場合は、PC から共有するか、音声はマイク経由になることを理解する。
- エコーが出る事例が報告されている 🔶。ヘッドセット使用が確実。

## 4. 権限と設定 ⚪
- 設定 → 対象アプリ → カメラ／マイク をオン。
- Stage Manager（ステージマネージャ）使用時はウィンドウ配置で画面共有の対象が変わることがある ⚠️。
- 外部ディスプレイ接続時の共有の見え方はアプリ依存 ⚠️。

## 5. 周辺機器 ⚪
- Bluetooth ヘッドセット、USB-C 接続のマイク／カメラは機種により対応が異なる。
- スタンドを使い、カメラの高さを目線に合わせる。

## 6. 負荷とバッテリー ⚪
- 会議中は発熱しやすい。充電しながらの長時間利用では保護機能で画質が落ちる場合がある。
