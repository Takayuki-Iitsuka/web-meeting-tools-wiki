# Windows でのビデオ会議

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証、手順名や画面は版により異なる）・⚠️未確認

## 1. 概要
最も選択肢が広い環境。主要ツールは専用アプリとブラウザの両方で利用できる ⚪。

## 2. ツール別の対応（確認できた範囲）
| ツール | 方式 | 根拠 |
|---|---|---|
| Microsoft Teams | デスクトップアプリ（64/32bit）、ブラウザ（Edge/Chrome/Firefox 直近3版） | ✅ |
| Google Meet | ブラウザ（Chrome/Firefox/Edge/Safari 現行版） | ✅ |
| Webex | Windows 10/11 対応、CPU は Intel デュアルコア 2.xx GHz または AMD（RAM 2GB 推奨） | ✅ |
| Slack ハドル | デスクトップアプリ、Chrome、Firefox | ✅ |
| Jitsi Meet | ブラウザ／デスクトップアプリ | 🔶 |
| FaceTime | 参加のみ（Chrome/Edge） | ✅ |
| Zoom・LINE・Whereby・Discord | アプリあり ⚪ | 要確認 ⚠️ |

## 3. 初期設定チェックリスト ⚪
1. **カメラ／マイクの許可**: 設定 → プライバシーとセキュリティ → カメラ／マイク。「アプリがカメラ／マイクにアクセスできるようにする」と、対象アプリ（またはブラウザ）をオンにする。
2. **既定の音声デバイス**: 設定 → システム → サウンド で入力・出力を明示。Bluetooth ヘッドセットは「ハンズフリー」と「ステレオ」で音質が変わる（通話時に音質が落ちることがある）。
3. **電源プラン**: ノートPCでバッテリー駆動中は省電力モードで映像が劣化することがある。会議中は電源接続を推奨。
4. **グラフィックス設定**: ブラウザ会議が重い場合、ハードウェアアクセラレーションの有無を切り替えて比較する。
5. **通知**: 集中モード（フォーカス）を有効にして共有中の通知漏れを防ぐ。

## 4. 画面共有のポイント
- ウィンドウ共有は仮想デスクトップや最小化に弱い。共有する窓を最小化しない ⚪。
- 複数ディスプレイ時は「画面」単位で選ぶと切替が楽。機密のあるディスプレイは共有しない。
- 動画再生を共有するときは、アプリ側の「コンピューター音声を共有」オプションを確認 ⚪。
- 共有が白っぽい場合は OS の HDR をオフ。Win+Alt+B で切替可能 ✅（Jitsi FAQ の記載）。

## 5. PC負荷の抑え方 ⚪
- ブラウザタブと常駐アプリを減らす。
- 仮想背景・ノイズ除去・ギャラリー表示数を必要最小限に。
- 起動時に自動実行されるアプリを整理（タスクマネージャー → スタートアップ）。
- 受信映像の画質を下げられるツールでは下げる。
