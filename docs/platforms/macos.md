# macOS でのビデオ会議

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証、手順名や画面は版により異なる）・⚠️未確認

## 1. 概要
Apple 製品のため FaceTime が標準で使える。Teams や Meet も利用可能。権限（プライバシー）の設定が必須で、特に **画面収録** の許可忘れが典型的なトラブル ⚪。

## 2. ツール別の対応（確認できた範囲）
| ツール | 方式 | 根拠 |
|---|---|---|
| FaceTime | 標準アプリ。リンクを作成可能（macOS Monterey 以降）| ✅ |
| Microsoft Teams | アプリは「最新3世代の macOS」、Intel/Apple silicon 共通インストーラ。RAM 4.0GB・空き1.5GB・解像度 1200×800 以上 | ✅ |
| Google Meet | ブラウザ（Chrome/Firefox/Edge/Safari） | ✅ |
| Slack ハドル | デスクトップアプリ。描画（Draw）は Mac で利用可 | ✅ |
| その他 | アプリあり ⚪ | ⚠️ 要確認 |

## 3. 権限設定（システム設定 → プライバシーとセキュリティ）⚪
| 項目 | 用途 | 注意 |
|---|---|---|
| カメラ | 映像 | ブラウザ会議ではブラウザ側に許可 |
| マイク | 音声 | 許可後、アプリ再起動が必要なことがある |
| 画面収録（画面とシステムオーディオの収録） | 画面共有 | **許可後にアプリの再起動が必要**。許可しないと共有時に壁紙だけが見える／黒画面になる |
| アクセシビリティ | リモート制御 | 共有画面の操作を渡す場合 |

## 4. 音声共有 ⚪
- macOS は標準ではシステム音声の取り込みに制限があり、会議ツール側が対応していない場合は共有に音が乗らない。ツールの「サウンドを共有」オプションの有無を確認。
- 回避策として仮想オーディオデバイスを使う方法があるが、設定は複雑で自己責任。

## 5. 負荷とバッテリー ⚪
- Apple silicon は効率が高いが、仮想背景＋ギャラリー表示＋画面共有の同時利用で発熱する。
- ブラウザは Safari が省電力とされるが、会議ツールによっては Chrome の方が互換性が高い。
- 外部ディスプレイ接続時は GPU 負荷が上がる。

## 6. 注意
- 複数の Apple 端末がある場合、FaceTime の通話が他端末でも鳴る。引き継ぎ（Handoff）の挙動は ⚠️ 未確認。
