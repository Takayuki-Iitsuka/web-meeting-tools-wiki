# Android でのビデオ会議

> 確認日: 2026年11月3日（皇紀2686年・令和8年）／ 信頼度: ✅公式確認 ・🔶二次情報 ・⚪一般的知見（出典未検証、手順名や画面は版により異なる）・⚠️未確認

## 1. 概要
端末・OSバージョンの幅が広く、機種依存の挙動が多い。アプリの最低OS要件を確認し、省電力設定とアプリの権限が主な落とし穴 ⚪。

## 2. ツール別の対応（確認できた範囲）
| ツール | 内容 | 根拠 |
|---|---|---|
| Google Meet | Android 5.0 以上（Gmail アプリ内会議は Android 6 以上） | ✅ |
| Microsoft Teams | アプリあり。モバイルブラウザは非対応 | ✅ |
| Slack ハドル | モバイルアプリ。画面共有は「…」→画面を共有 | ✅ |
| FaceTime | ブラウザ（Chrome）で参加のみ。SharePlay・画面共有不可 | ✅ |
| Jitsi Meet | アプリあり。画面共有の可否は古いレビューで不一致 | 🔶 |
| 他ツール | アプリあり ⚪ | ⚠️ 要確認 |

## 3. 初期設定 ⚪
1. 設定 → アプリ → 対象アプリ → 権限 で **カメラ・マイク** を許可。
2. 通知を許可（会議の呼び出しが届くため）。
3. **バッテリー最適化から対象アプリを除外**（バックグラウンド切断対策）。メーカーにより名称と場所が異なる。
4. データセーバーをオフ、またはアプリを例外に。
5. Bluetoothヘッドセットはアプリ内でも出力先を確認。

## 4. 画面共有 ⚪
- 画面共有は OS の画面キャプチャ機能（MediaProjection）を使う。開始時に確認ダイアログが出る。
- 共有中は通知内容が映る。事前に「サイレント」または通知の非表示を設定。
- 内部音声（アプリ音）の共有可否は端末・OS・ツールに依存 ⚠️。

## 5. 負荷とバッテリー ⚪
- 画面を点灯したままカメラ＋通信を続けるため、バッテリー消費・発熱が大きい。60 分を超える会議は充電しながら。
- モバイル回線では、受信映像の品質を下げる、または音声のみで参加するとデータ量を抑えられる。
- 多人数会議では映像を最小限にする。

## 6. 注意
- 機種・Androidのバージョンにより、挙動が違うことがある。同一環境で事前にテスト会議を。
