# 用語集

| 用語 | 説明 |
|---|---|
| WebRTC（Web Real-Time Communication／ウェブ実時間通信） | ブラウザで音声・映像通信を行う標準技術。Meet、Whereby、Jitsi 等が利用。 |
| SFU（Selective Forwarding Unit／選択転送装置） | サーバが各参加者の映像を転送する方式。多人数会議の主流。 |
| MCU（Multipoint Control Unit／多地点接続装置） | サーバで映像を合成して配信する方式。端末負荷は低いがサーバ負荷が高い。 |
| E2EE（End-to-End Encryption／端末間暗号化） | 通信の両端のみが復号できる暗号化。有効化で一部機能（クラウド録画等）が制限される場合がある。 |
| 待機室（Waiting Room／Lobby） | 主催者が承認するまで参加者を入室させない機能。 |
| 仮想背景（Virtual Background） | 背景を画像・ぼかしに置換する機能。端末性能に依存。 |
| ブレイクアウトルーム（Breakout Room／分科会室） | 会議内の少人数グループ分割機能。 |
| ウェビナー（Webinar） | 少数の登壇者と多数の視聴者で行う配信型会議。 |
| SIP / H.323 | 会議専用端末・会議室システムとの相互接続に用いるプロトコル。 |
| ゲスト参加（Guest Join） | アカウントなし（または他組織のアカウント）での参加。 |
| ブロードキャスト拡張（Broadcast Extension） | iOS/iPadOS で画面共有を実現する仕組み。 |
| MediaProjection | Android で画面キャプチャを行う API。 |
